# 小黄的教室

互动式学科教室 monorepo：从学科大厅进入各科实验室。当前以**化学**为完整模块，**数学**教室已接入；物理 / 生物等学科壳层预留中。

- 仓库：https://github.com/xingyingyuzhui/Xiao-Huang-s-Classroom
- 作者：星影欲坠

## 结构概览

| 路径 | 说明 |
|------|------|
| `apps/web` | Vite 前端（大厅、学科教室、主题） |
| `apps/server` | Express + SQLite 后端 |
| `apps/desktop` | Electron 桌面端 |
| `packages/*` | 共享包（如表达式、学科设置） |
| `test/*` | 服务端 / 前端 / 共享测试 |

本地开发（仓库根目录）：

```bash
npm install
npm run dev:server   # 后端
npm run dev          # 前端
```

更多约定见根目录 `AGENTS.md`。
