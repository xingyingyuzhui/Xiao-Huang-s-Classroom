# 小黄的教室 · 学科大厅设计（v1）

**日期：** 2026-07-29  
**状态：** 已批准，实现中

## 目标

在保留化学实验室完整体验的前提下，增加「学科大厅 → 进入学科」的一级导航。v1 仅接通化学；其它学科灰显占位。

## 交互

1. **启动默认进入学科大厅**（全屏）。
2. 大厅展示学科卡片：化学可进入；其它（物理等）灰显「即将推出」。
3. 进入化学后呈现现有顶栏 Tab + 各功能面板。
4. **顶栏**：品牌「小黄的教室」右侧学科标签（默认「化学」），**可点击返回大厅**。
5. **设置抽屉顶栏**：「设置」标题右侧「学科大厅」按钮，返回大厅并关闭抽屉。
6. 处于大厅时隐藏学科标签与功能 Tab（或 Tab `aria-hidden`）；回到大厅不销毁化学模块状态（仅切换壳层显示）。

## 模块边界

| 文件 | 职责 |
| --- | --- |
| `src/subjects/catalog.js` | 学科元数据（id/name/status） |
| `src/subjects/session.js` | 当前学科读写（可持久化） |
| `src/subjects/hub.js` | 大厅渲染与进入/返回 |
| `src/main.js` | 编排：hub ↔ lab shell |
| `src/styles/_subject-hub.css` | 大厅与标签样式 |

不新建第二套 Tab 编排器；化学功能仍由现有 `main.js` tab 逻辑拥有。
